# Aggregate reproducibility outputs

These files were generated by the completed authorized reproducibility run. They contain aggregate statistics only.

The original run archive also contained patient-level score files and serialized model/preprocessor artifacts. Those restricted files are intentionally excluded from this public repository.

The run used `catboost==1.2.10` solely as an import dependency of the official PULSNAR package. It was not evaluated as a candidate model. Because the software table was written before CatBoost was added to the inventory, it does not appear in `versions.csv`; the public `requirements.txt` records it explicitly.

`shap_global.csv` reports transformed model columns. In manuscript reporting, the two one-hot Gender columns are aggregated into the single clinical feature **Gender**. The executed notebook verified an aggregated mean absolute raw-margin SHAP value of `0.1381318886` against the frozen expected value `0.138132`.
